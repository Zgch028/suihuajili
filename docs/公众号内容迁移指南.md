## 二、迁移总流程（推荐顺序）

```
① 盘点公众号 → ② 补全/修正系列页 → ③ 批量搬运文章 → ④ 处理配图 → ⑤ 本地预览 → ⑥ commit + push 自动部署
```

### 第一步：盘点公众号合集与文章

先不要急着复制粘贴。打开公众号后台，把每个合集里的文章列一张表：

| 序号 | 公众号合集名 | 对应网站 series slug | 文章标题 | 发布日期 | 原文链接 | 是否需要搬运 | 备注 |
|---|---|---|---|---|---|---|---|
| 1 | 大宋纪丽 | dasongjili | 点茶不是泡茶：从一盏建盏看宋人的慢 | 2026-06-18 | https://mp.weixin.qq.com/... | 是 | 已搬运 |
| 2 | 十二生肖职场人格解码 | shiershengxiao | 像狗一样守护 | 2026-08-17 | https://mp.weixin.qq.com/... | 是 | 已搬运 |

> 已提供 Excel 盘点表：`docs/公众号内容盘点表.xlsx`，已按后台第 1、2 页截图填好 20 行合集级数据；其中「文章标题 / 发布日期 / 原文链接」三列需要你从后台逐篇复制。

#### 1.1 后台复制文章清单的最快做法

在公众号后台按这个顺序操作，每次只处理一个合集：

1. 登录公众号后台 → **内容与互动 → 合集**。
2. 找到要搬运的合集，点击右侧 **「编辑」**。
3. 进入合集详情后，你会看到该合集下所有文章的列表（标题 + 发布时间 + 状态）。
4. 逐篇点击文章标题，在新标签页打开文章。
5. 复制该文章的 **标题**、**发布时间**、**原文链接（浏览器地址栏里的 `https://mp.weixin.qq.com/s/...`）**。
6. 回到 Excel 盘点表，找到对应合集行，在下方新增行（序号递增），把三列数据填进去：

| 列 | 填什么 |
|---|---|
| 公众号合集名 | 保持与第一行合集名一致 |
| 对应网站 series slug | 保持与第一行 slug 一致 |
| 文章标题 | 复制公众号文章标题 |
| 发布日期 | 格式 `2026-08-17` |
| 原文链接 | `https://mp.weixin.qq.com/s/xxxxxxxx` |
| 是否需要搬运 | 默认填「是」；不想搬的填「否」 |
| 备注 | 可选，比如「已搬运 / 需重配图 / 含视频」 |

> **技巧**：每处理完一个合集，就在「备注」第一行标注「后台共 N 篇，已盘点 M 篇 / 待搬运 K 篇」，防止漏项。

#### 1.2 也可以把后台列表截图给我

如果你不想手动填 Excel，可以：
- 逐个合集点击「编辑」进入文章列表；
- 每页截图发给我；
- 我帮你识别标题、发布时间，整理成 Excel。

但**原文链接**公众号后台截图里通常没有，需要你在文章列表页逐篇点击复制链接，或者发我截图后我再尝试通过公开搜索补链接。

### 第二步：确认每个 series 是否需要新建

- 如果公众号合集名称与网站现有系列**完全对应** → 直接复用现有 `.md`，只改描述/SEO 字段。
- 如果有**新的公众号合集**（如「AI 学习笔记」「监理日志自动化」）→ 新建一个 `src/content/series/xxx.md`。

### 第三步：一篇文章一篇文章搬运

每篇公众号文章对应一个 `src/content/posts/文章标题的英文或拼音.md`。

复制内容时建议：
- 不要直接复制公众号后台 HTML（会带大量微信样式）。
- 在公众号文章页面「复制」正文到记事本，去掉格式后，再按 markdown 重新排版。
- 标题层级统一用 `# 一级标题`、`## 二级标题`、`### 三级标题`。
- 段落之间空一行。
- 金句、引用用 `>` 引用块。

### 第四步：处理图片

1. 在公众号文章里把图片「另存为」到电脑。
2. 按规则命名：`系列slug-文章slug-序号.jpg`，例如 `dasongjili-diancha-01.jpg`。
3. 放到 `public/images/posts/` 目录下。
4. 在 markdown 里引用：
   ```markdown
   ![点茶击拂](\images\posts\dasongjili-diancha-01.jpg)
   ```

> 如果公众号文章配图很多，可以一次性把所有图存到 `public/images/posts/待整理/` 里，文章写好后再重命名。

### 第五步：本地预览

```bash
npm run build
npm run preview
```

或直接用：
```bash
npm run dev
```

打开 `http://localhost:4321/series/dasongjili/` 等页面检查。

### 第六步：提交部署

```bash
git add -A
git commit -m "content: 迁移公众号《xxx》系列 x 篇"
git push origin main
```

等 GitHub Actions 变绿即可。

## 三、文件模板

### 3.1 新建系列页模板

参考模板：`docs/series-template.md`  
新建文件：`src/content/series/新系列slug.md`

```markdown
---
title: 系列中文名
eyebrow: SERIES · 分类标签
description: 一句话介绍这个系列在讲什么，50-80字。
tag: 分类 · 标签
seoTitle: 系列中文名｜岁华纪丽
seoDescription: 给搜索引擎看的描述，60-120字，包含核心关键词。
seoKeywords: [关键词1, 关键词2, 关键词3]
order: 8
headerImage: /series-bg/可选背景图.jpg
---

系列导语正文。可以写 2-4 段，介绍这个系列为什么值得读。
```

### 3.2 新建文章模板

参考模板：`docs/post-template.md`  
新建文件：`src/content/posts/文章slug.md`

```markdown
---
title: 文章完整标题
date: 2026-08-17
series: 所属series的slug
description: 文章摘要，50-120字，会出现在列表卡和 meta description。
tags: [标签1, 标签2, 标签3]
volume: 狗系列·第二篇
cover: /images/posts/封面图.jpg
---

文章正文从这里开始。

## 一、小标题

正文段落。

## 二、另一个小标题

> 金句可以用引用块。

![配图说明](/images/posts/图片文件名.jpg)

## 三、结尾

总结段落。
```

## 四、常见问题

### Q1：一篇文章可以属于多个 series 吗？

目前 schema 只支持一个 `series` 字段。如果某篇文章跨合集，建议：
- 主归属到一个最相关的 series；
- 在文章正文或标签里体现其它相关主题。

### Q2：公众号文章里的视频、音频、小程序卡片怎么办？

- **视频号视频**：建议用截图 + 文字说明 + 跳转视频号链接。
- **音频**：网站暂不支持直接播放，可用文字稿替代。
- **小程序卡片**：用文字描述 + 二维码图片替代。

### Q3：文章很多，有没有批量办法？

如果一次性搬运 10 篇以上，可以：
1. 先填好 Excel 盘点表；
2. 把文章正文按「标题 + 正文」格式整理好，每篇一个 `.md` 文件；
3. 发给我，我可以帮你批量校验 frontmatter、处理图片路径、构建部署。

### Q4：要不要在文章末尾加「原文地址」？

推荐加，既有SEO价值，也尊重原平台：
```markdown
> 本文首发于公众号「岁华纪丽」，原文链接：[点击阅读](https://mp.weixin.qq.com/...)
```
