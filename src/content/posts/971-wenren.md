"><font face="宋体"><span leaf="">刘鋹哭了。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">不是在朝堂上哭，不是在降表上哭，是在公安县的一个小驿站里哭的。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">四月，他被押送从岭南赴汴京。路过长江边上的公安县，驿站里的邸吏庞师进来拜见他。刘鋹问：这人是谁？</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">旁边的人说：</span></font><span leaf="">"</span><font face="宋体"><span leaf="">本国人也。</span></font><font face="Times New Roman"><span leaf="">"</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">刘鋹愣了</span></font><font face="Times New Roman"><span leaf="">——"</span></font><font face="宋体"><span leaf="">本国人</span></font><font face="Times New Roman"><span leaf="">"</span></font><font face="宋体"><span leaf="">是什么意思？</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">黄德昭解释了：</span></font><span leaf="">"</span><font face="宋体"><span leaf="">高皇帝（刘鋹的祖父刘隐）在藩的时候，每年向大朝（中原王朝）进贡，辎重都要经过荆州。所以让庞师进在公安置了邸</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">就是驿站，专门用来接待南汉的贡使、造车乘运货物的。这邸从你祖父那会儿就有了，一直在。</span></font><font face="Times New Roman"><span leaf="">"</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">刘鋹听完，叹了一口气。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">他说：</span></font><span leaf="">"</span><font face="宋体"><span leaf="">我在位十四年，未尝闻此言。今日始知祖宗山河及大朝境土也。</span></font><font face="Times New Roman"><span leaf="">"</span></font></span></p><section><section style="display: inline-block;"><img data-ratio="0.7497886728655959" data-type="jpg" data-w="1183" src="/images/posts/971-wenren-body-3.jpg"></section></section><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">然后他哭了</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">泣下久之。</span></font></span><br></p><p><span style="  font-size:12.0000pt; "><span leaf="">"</span><font face="宋体"><span leaf="">我在位十四年，未尝闻此言。</span></font><font face="Times New Roman"><span leaf="">"</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">十四年。当皇帝十四年。十四年里不知道自己祖父曾经每年向中原进贡，不知道南汉在大宋旁边只是一个小国，不知道自己祖宗的江山有多小、大朝的疆土有多大</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">不知道真实的世界是什么样子的。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">为什么不知道？因为被蒙蔽了。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">南汉的朝廷，是一个被宦官和佞臣层层包裹的朝廷。刘鋹信任宦官</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">宦官龚澄枢、李托等掌控朝政，凡是有能力的大臣都被杀或被贬，剩下的都是听话的。听话的人不会告诉皇帝真相</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">真相是南汉只是一个小国、大朝是天下之主、南汉每年要向大朝进贡才能存活。这些真相刘鋹不知道，因为没人告诉他</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">告诉他的人已经被杀或被贬了。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">他被包裹在一个虚假的世界里</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">这个世界里南汉是大国、刘鋹是明君、宦官是忠臣、大朝是可以忽视的远方。这个虚假的世界里没有公安县的邸吏、没有每年进贡的辎重、没有祖父向中原称臣的事实</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">这些真实的信息被减掉了，减掉了之后他看不见真实的世界了。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">被蒙蔽的人看不见真实。蒙蔽减掉了真实信息，减掉了真实信息人就活在虚假里了。活在虚假里的人做虚假的判断</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">以为南汉很强、以为大朝很远、以为宦官可信、以为自己的江山很大。虚假的判断导致虚假的决策</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">不备兵、不修城、不向大朝求和、不信任大臣。虚假的决策导致真实的后果</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">南汉灭亡了。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">刘鋹在公安县听到真相的那一刻，十四年的蒙蔽减了。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">减了蒙蔽才能看见真实。看见真实才能知道</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">自己的祖宗不是大国之主，是大朝的藩臣；自己的江山不是天下之疆，是大朝旁边的一小块；自己的朝廷不是能人之朝，是宦官之朝；自己的十四年不是治世之十四年，是被蒙蔽之十四年。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">看见真实之后他哭了</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">不是因为亡国，是因为十四年活在虚假里。十四年里做的所有判断都是基于虚假信息的</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">我以为南汉很强，结果不强；我以为宦官可信，结果不可信；我以为大朝很远，结果就在旁边；我以为自己的江山很大，结果很小。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">十四年的蒙蔽减了之后看见了真实</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">看见真实之后他发现自己十四年活在了错误的世界里。错误的世界不是他选的</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">是蒙蔽者帮他选的。蒙蔽者减掉了真实信息，他活在虚假里了。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">刘鋹还有一件事</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">疑酒有毒。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">从帝幸讲武池，诏赐卮酒。鋹疑之，奉杯泣曰：</span></font><span leaf="">"</span><font face="宋体"><span leaf="">臣承祖父基业违拒朝廷劳王师致讨罪固当诛。陛下既待臣以不死愿为大梁布衣观太平之盛，未敢饮此酒。</span></font><font face="Times New Roman"><span leaf="">"</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">他为什么疑酒有毒？因为他在南汉的时候常用毒酒杀臣下</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">他自己就是用毒控制别人的，所以本能地以为别人也会用毒对付他。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">施毒者总以为别人也会施毒</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">以己度人的恐惧，是跨越千年的心理机制。你在黑暗中做的事让你以为别人也在黑暗中做事。你的手段变成了你的恐惧</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">你用什么手段控制别人，你就害怕别人用什么手段对付你。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">赵匡胤笑了</span></font><font face="Times New Roman"><span leaf="">——"</span></font><font face="宋体"><span leaf="">朕推心置人腹，安有此事！</span></font><font face="Times New Roman"><span leaf="">"</span></font><font face="宋体"><span leaf="">然后他拿起刘鋹那杯酒自己喝了，另斟一杯给刘鋹。</span></font></span></p><section><section style="display: inline-block;"><img data-ratio="0.7497886728655959" data-type="jpg" data-w="1183" src="/images/posts/971-wenren-body-4.jpg"></section></section><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">赵匡胤喝了那杯酒</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">不是演戏，是真的喝了。喝了之后刘鋹大惭</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">惭愧的不是疑了酒有毒，是发现自己十四年的世界观全是错的：我以为别人和我一样用毒控制人，结果别人推心置腹不设毒；我以为宦官可信结果宦官蒙蔽我；我以为自己的江山很大结果很小；我以为大朝很远结果就在旁边。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">十四年的蒙蔽减了</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">减了之后看见了一个完全不同的真实世界。真实世界里没有毒酒（赵匡胤喝了那杯酒证明无毒），没有虚假（公安县的邸吏告诉他真实的祖宗山河），没有蒙蔽（没人再帮他减掉真实信息了）。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">看见真实之后他惭了</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">惭了之后大概也松了。松了不是因为亡国，是因为终于看见了真实的世界。看见了真实的世界才能做真实的判断</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">虽然现在已经晚了（南汉已经亡了），但看见真实本身是一种减负</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">减掉了蒙蔽就减掉了虚假，减掉了虚假就看见了真实。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">蒙蔽是一种不该有的负担。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">蒙蔽减掉了真实信息</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">你不知道真实的世界是什么样子、不知道真实的局势是什么状态、不知道真实的自己是什么处境。你活在虚假里</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">虚假的世界、虚假的局势、虚假的处境。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">活在虚假里的人做虚假的判断</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">刘鋹以为南汉很强做了不备兵的判断，以为宦官可信做了信任宦官的判断，以为大朝很远做了不求和的判断。虚假的判断导致真实的后果</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">南汉灭亡了。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">蒙蔽不该有。真实信息不该被减掉</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">该有的信息该有，不该减掉真实让人活在虚假里。减掉蒙蔽减掉了不该有的（虚假信息），看见了该有的（真实信息）。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">去掉蒙蔽才能看见真实。看见真实才能做真实判断。真实判断才能做出正确选择。正确选择才能走对路。走对路才能过好日子。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">减掉蒙蔽是减负的一种</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">不是减掉了钱（暗税），不是减掉了命（求巫），是减掉了信息（虚假信息）。信息不该被减掉</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">减掉了信息人就瞎了，瞎了就走错路，走错路就过坏日子。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">刘鋹过了十四年的坏日子</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">不是因为日子本身坏，是因为蒙蔽让他看不见真实，看不见真实让他做了错判断，错判断让他走错路，走错路让南汉亡了。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">减掉蒙蔽之后他看见了真实</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">看见了真实之后他哭了。哭了不是因为难过，是因为十四年的虚假减了之后忽然看见了真实。看见真实那一刻的震撼</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">原来真实的世界是这样的，原来我十四年活在虚假里，原来我做的判断全错了。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">震撼之后是惭</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">惭了自己十四年被蒙蔽。惭之后是松</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">松了是因为终于看见了真实，看见了真实就能重新做了。虽然南汉已经亡了不能再做了，但看见真实本身就是减负</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">减掉了蒙蔽就减掉了虚假，减掉了虚假就看见了真实。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">看见了真实就松了</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">松了是因为不再活在虚假里了。不再活在虚假里就踏实了</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">踏实了是因为看见的世界是真实的、做的判断是真实的、走的路是真实的。</span></font></span></p><section><section style="display: inline-block;"><img data-ratio="0.7497886728655959" data-type="jpg" data-w="1183" src="/images/posts/971-wenren-body-5.jpg"></section></section><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">一千年前，一个当了十四年皇帝的人在公安县的小驿站里第一次听说了自己祖宗的真实山河。他哭了</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">不是因为亡国，是因为十四年被蒙蔽忽然看见了真实。</span></font></span><br></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">一千年后，我们大概也有过类似的体验</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">某个时刻忽然看见了真实的世界。那个真实和之前以为的完全不同</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">之前以为的世界是蒙蔽者帮我们选的，忽然看见了真实的世界是自己发现的。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">那种震撼不壮烈，就是忽然明白了</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">原来真实是这样的，原来我之前活在虚假里。明白了之后心里松了</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">不再活在虚假里了，不再做虚假的判断了，不再走错路了。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">减掉蒙蔽看见真实。看见真实做真实判断。真实判断走对路。走对路过好日子。</span></font></span></p><p><span style="  font-size:12.0000pt; "><font face="宋体"><span leaf="">减掉不该有的蒙蔽，看见该有的真实。减了不该有的加了该有的</span></font><font face="Times New Roman"><span leaf="">——</span></font><font face="宋体"><span leaf="">日子就对了。对了就够了。</span></font></span></p><section><span leaf=""><br></span></section><p style="display: none;"><mp-style-type data-value="3"></mp-style-type></p>
