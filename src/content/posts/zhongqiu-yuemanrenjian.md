color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">中秋的源头，比我们想的要古老。</span></section><section data-layout-id="9" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">“中秋”一词，最早见于《周礼》。先秦时期，帝王就有“秋分夕月”的礼制。《礼记》里写得明白：“天子春朝日，秋夕月。朝日以朝，夕月以夕。”春天祭日，秋天祭月——太阳和月亮，一个管白昼，一个管黑夜，一个主生发，一个主收敛。古人把这两件事安排得清清楚楚。</span></section><section data-layout-id="10" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">秋分曾是传统的“祭月节”。但秋分在八月里的日期每年不同，不一定赶上圆月。祭月而无月，实在大煞风景。于是人们把祭月的日子往后挪，挪到了农历八月十五——月亮最圆的那一天。</span></section><section style="text-align: center" nodeleaf=""><img class="rich_pages wxw-img" data-ratio="0.7497887015342712" data-type="jpg" data-w="1183" type="block" data-aiimagesource="0" src="/images/posts/zhongqiu-yuemanrenjian-body-3.jpg"></section><section><span leaf=""><br></span></section><section data-layout-id="11" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">这个调整，意味深长。中国人把“祭月”变成了“赏月”，把敬畏变成了亲近。月亮从神坛上走下来，走进了庭院，走进了酒杯，走进了每一个抬头望天的人的心里。</span></section><section data-layout-id="12" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">到了唐代，中秋与嫦娥奔月、吴刚伐桂、玉兔捣药的神话结合，玩月之风大兴。李白“举杯邀明月”，杜甫“月是故乡明”，王维“明月松间照”——多少千古名句，都在月色里诞生。宋代正式把中秋定为节日，夜市通宵达旦，酒楼张灯结彩，热闹得像过年。</span></section><section data-layout-id="13" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">从天文学上看，中秋的月亮确实最圆最亮。此时太阳直射赤道附近，月亮运行到近地点，视觉上最大最亮。但中国人不满足于天文解释。我们更愿意相信：月亮在这一夜格外圆，是因为人心在这一夜格外盼。</span></section><section data-layout-id="14" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">盼一个“圆”字。月圆、饼圆、人圆、事圆——中秋的所有习俗，都在围绕“圆满”做文章。</span></section><h1 data-layout-id="15" style="font-size: 20px; font-weight: 500; color: #2B77BF; line-height: 1.8; margin-bottom: 12px; text-align: center"><span leaf="">二、人事：饼圆如月，灯映万家</span></h1><section data-layout-id="16" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">中秋的烟火气，是带着甜味的。</span></section><h2 style="font-size: 17px; font-weight: 500; color: #2B77BF; line-height: 1.8; margin-bottom: 24px; text-align: left" data-layout-id="17"><span leaf="">月饼，是最有仪式感的吃食。</span></h2><section style="text-align: center" nodeleaf=""><img class="rich_pages wxw-img" data-ratio="0.7497887015342712" data-type="jpg" data-w="1183" type="block" data-aiimagesource="0" src="/images/posts/zhongqiu-yuemanrenjian-body-4.jpg"></section><section><span leaf=""><br></span></section><section data-layout-id="18" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">它最初是祭月的供品。月神享用了，人才敢动口。后来，人们逐渐把中秋赏月与品尝月饼，作为家人团圆的象征。圆圆的饼，像一轮小小的月亮，咬一口，仿佛把月光吃进了肚子里。</span></section><section data-layout-id="19" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">南北风味在这只小小的饼里各自精彩。广式莲蓉蛋黄，甜中带咸，皮薄馅厚；苏式鲜肉月饼，酥皮层层分明，一口下去肉汁四溢；京式自来红、自来白，冰糖青红丝藏着老北京的记忆；滇式云腿月饼，咸甜交融，火腿香浓。各家各味，但掰开月饼的动作是一样的——一家人分一块，一人一角，吃的是饼，咽下的是“我们在一起”。</span></section><section data-layout-id="20" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">关于月饼，还有个传说。元代末年，朱元璋联合各路力量准备起义，但朝廷搜查严密，传递消息困难。军师刘伯温想出一计：把藏有“八月十五夜起义”的纸条塞进饼子里，分头送到各地起义军手中。起义成功后，月饼成了赏赐群臣的节令糕点。传说真假难考，但中国人把“团圆”和“反抗”同时包进一只饼里，倒是很符合我们的性格——温柔里有硬气。</span></section><h2 style="font-size: 17px; font-weight: 500; color: #2B77BF; line-height: 1.8; margin-bottom: 24px; text-align: left" data-layout-id="21"><span leaf="">燃灯，是中秋夜的另一种浪漫。</span></h2><section style="text-align: center" nodeleaf=""><img class="rich_pages wxw-img" data-ratio="0.7497887015342712" data-type="jpg" data-w="1183" type="block" data-aiimagesource="0" src="/images/posts/zhongqiu-yuemanrenjian-body-5.jpg"></section><section><span leaf=""><br></span></section><section data-layout-id="22" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">中秋之夜，天清如水，月明如镜，可人们并不满足。于是有了燃灯助月色的风俗。湖广一带有用瓦片叠塔燃灯的习俗，江南一带有制灯船的习俗。广东张灯最盛，各家于节前十几天就用竹条扎灯笼，做成鸟兽鱼虫形状，上面糊色纸、绘彩图。中秋夜，灯内燃烛，用绳系于竹竿上，高竖于瓦檐或露台，俗称“树中秋”或“竖中秋”。</span></section><section data-layout-id="23" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">香港大坑的舞火龙，更是壮观。从八月十四晚起，一连三晚，一条七十多米长的火龙穿街过巷。龙身用珍珠草扎成，插满长寿香，火光点点，如真龙降临。广东潮汕、江西等地有烧塔习俗，砖瓦砌塔，火从塔底烧到塔顶，火光冲天，寓意日子红火。杭州有钱塘江观潮盛事，大潮奔涌而来，与中秋圆月遥相呼应。</span></section><section data-layout-id="24" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">月光是大家的，灯火是自家的。中秋的浪漫，是公共与私密同时发生的时刻。</span></section><h2 style="font-size: 17px; font-weight: 500; color: #2B77BF; line-height: 1.8; margin-bottom: 24px; text-align: left" data-layout-id="25"><span leaf="">还有兔儿爷。</span></h2><section data-layout-id="26" style="font-size: 17px; font-weight: 400; color: rgba(0,0,0,0.9); line-height: 1.8; margin-bottom: 24px"><span leaf="">老北京中秋，兔儿爷是标志性的物件。泥塑的兔子，兔首人身，披甲胄，插护背旗，脸贴金泥，身施彩绘，或坐或立，或捣杵或骑兽。孩子们提着兔儿爷灯，跑来跑去，烛光在纸肚子里轻轻摇晃。那种光，温暖、朦胧，像把月亮摘了一小块，揣在怀里。</span></section><h1 data-layout-id="27" style="font-size: 20px;
